# Interactive UI Prototype

Open [index.html](index.html) in a browser or use GitHub's file preview to inspect the source. For a live preview, download the file and open it locally; it has no build dependencies.

## Included interactions
- Lobby with three original demo-game cards.
- Mock email/password form validation (no credentials are sent or stored).
- Skyline Crash scripted multiplier animation.
- Neon Reels local symbol simulation using temporary demo credits.
- Reef Ranger tap-to-score interaction.
- Temporary local activity history and reset.

## Important limitations
This is a standalone UX prototype, not the Cocos Creator client and not connected to Spring Boot/MySQL. It uses client-side-only simulated state, which is not secure or authoritative. Do not use it for real accounts, real value, production data, or real-money gaming. The production client must call backend endpoints and trust only server-validated results.
